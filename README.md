# ⚜ Eden Guild · 伊甸园公会管理系统

一个纯前端 + 轻量 Node 后端的**公会会员管理系统**，含客户端（会员门户）与管理端（管理员后台）双站点。数据存服务器共享存储，多设备实时同步。

> ⚠️ 本仓库为**通用开源版本**，已移除线上敏感信息（真实服务器地址、会员数据快照）。**初始管理员账号：`root` / `123123`**（仅限本开源版初始状态，部署后请立即登录后台修改为强密码）。

---

## ✨ 功能特性

**客户端（会员门户）**
- 激活码注册 / 账号密码登录
- 公会大厅、编队系统、评分上报与排行、捐献提交与排行（含凭证图片）
- 公会金库（资源管理）、建筑升级系统
- 个人资料：头像（自动压缩）、修改密码、自定义称号
- 记住账号密码（本地混淆存储）

**管理端（后台）**
- 管理员账号密码登录（防爆破：同 IP+账号 5 次失败锁 15 分钟）
- 会员管理：授权金库/编队/建筑权限、自定义称号、移除会员
- 激活码管理：单条添加、批量生成（EDEN- 格式）、删除
- 捐献 / 评分审核（批准 / 拒绝 / 删除）
- 数据导出 / 导入备份

**安全机制**
- 所有管理接口需 admin Token 鉴权（24h 会话），响应脱敏（永不下发明文密码）
- **设备绑定**：注册即绑定设备指纹，每账号最多 2 台设备（电脑 + 手机），新设备登录需管理员后台授权，可单独解绑任一台
- 设备类型识别：后台待授权申请标注 📱 手机 / 💻 电脑
- 删除用户即时销毁其会话（强制下线），被删账号自动登出
- 登录审计日志（成功 / 失败 / 绑定 / 解绑 / 授权全记录）

## 🛠 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生 HTML + JavaScript 单页应用（无框架，单文件） |
| 后端 | Node.js 原生 http（无依赖） |
| 反向代理 | Caddy（`/api/*` → Node；`/admin*` → 同一前端） |
| 存储 | 服务器 JSON 文件（`/var/lib/eden/data.json`） |
| 部署 | systemd 服务 + Caddy / HTTPS |

## 📁 项目结构

```
├── eden_index.html    # 前端单页应用（客户端 + 管理端双站点）
├── eden-server.js     # Node 后端（API / 鉴权 / 设备绑定 / 防爆破 / 审计日志）
└── Caddyfile          # Caddy 反向代理配置示例（含 /admin 路由与缓存控制）
```

## 🚀 部署

### 1. 后端

```bash
# 将 eden-server.js 放到服务器，例如 /opt/eden/
node /opt/eden/server.js   # 默认监听 127.0.0.1:8080
# 建议用 systemd 托管：
# systemctl enable --now eden-api
```

### 2. 前端 + 反代

```bash
# 将 eden_index.html 放入 Caddy 站点根目录（如 /usr/share/caddy/index.html）
# 按 Caddyfile 示例配置反代；HTTPS 用 Caddy 自动证书或自签
sudo systemctl reload caddy
```

### 3. 初始化

- 首次启动后数据文件自动创建
- **初始管理员账号：`root` / `123123`**（开源版统一初始密码，部署后请立即登录后台修改密码）
- 注册会员需先在后台上传 / 生成激活码（格式 `EDEN-XXXXXXXX`）

---

## 🔒 安全说明

- 密码明文存储于服务端数据文件（轻量系统取舍），请做好数据文件权限与定期备份
- 客户端 localStorage 中"记住密码"为 base64 混淆，**不是加密**，勿在公共设备勾选
- 建议对数据文件配置每日自动备份
